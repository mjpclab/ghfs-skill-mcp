# Example prompts

Requests that should trigger the `ghfs-server` skill.

- "Install GHFS and serve `~/shared` on port 8080, read-only, reachable only
  from this machine."
- "Restart the GHFS server so people can upload to `/inbox` but not delete
  anything."
- "Serve `~/shared` over HTTPS on port 8443 with `server.crt` and `server.key`."
- "Require a username and password on the GHFS server."
